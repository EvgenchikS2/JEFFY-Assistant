# Бесплатные варианты для голоса

Условия проверены по официальной документации 13 октября 2026 года. Лимиты и доступность могут изменяться. Jeffy не выдаёт ключи и не включает чужие ключи.

| Вариант | Ключ | Распознавание русской речи | Ответы ИИ | Озвучка |
|---|---|---|---|---|
| Vosk + Windows | Не нужен | На компьютере | Не входит | Локальный голос Windows |
| Groq + Windows | [Создать в Groq Console](https://console.groq.com/keys) | Whisper Large V3 Turbo | GPT OSS 20B по умолчанию | Локальный голос Windows |
| Gemini + Windows | [Создать в AI Studio](https://aistudio.google.com/apikey) | Gemini принимает аудио | Gemini 2.5 Flash по умолчанию | Локальный голос Windows |
| OpenRouter + Vosk | [Создать в OpenRouter](https://openrouter.ai/settings/keys) | Vosk локально | `openrouter/free` | Локальный голос Windows |
| Ollama + Vosk | Не нужен | Vosk локально | Скачанная локальная модель | Локальный голос Windows |

## Что выбрать

Для управления ПК без регистрации начните с **Vosk + Windows**. Это работает без сети после загрузки модели, но точность коротких команд нужно проверить на вашем микрофоне.

Для разговоров с ИИ сначала попробуйте **Groq**, если его сервис доступен для вашего аккаунта и региона. В документации free plan указаны лимиты Whisper, а не безлимитная работа. На дату проверки Whisper Large V3 Turbo: 20 запросов в минуту, 2000 в день, 7200 секунд аудио в час и 28800 секунд в день. Реальные ограничения смотрите в своей консоли: [Groq Rate Limits](https://console.groq.com/docs/rate-limits). Формат и поддерживаемые языки: [Speech to Text](https://console.groq.com/docs/speech-to-text).

**Gemini** имеет бесплатные тарифы у ряда моделей: [Pricing](https://ai.google.dev/gemini-api/docs/pricing). В free tier контент может использоваться для улучшения продуктов Google. AI Studio требует возраст 18+ и поддерживаемый регион. Россия отсутствует в опубликованном списке доступных регионов на дату проверки: [Available regions](https://ai.google.dev/gemini-api/docs/available-regions). Поэтому Gemini нельзя обещать как работающий вариант для российского аккаунта.

**OpenRouter** предоставляет отдельные бесплатные модели и маршрутизатор `openrouter/free`. Их доступность и лимиты отличаются от платных: [Free models](https://openrouter.ai/collections/free-models/), [Free variant](https://openrouter.ai/docs/guides/routing/model-variants/free). В Jeffy этот сервис даёт ответы, а распознавание выполняет выбранный отдельный движок.

**Ollama** не требует API-ключа для локального сервера: [API introduction](https://docs.ollama.com/api/introduction). Загрузите модель, например `ollama pull qwen3:4b`, и запустите сервис. Время ответа и потребление памяти зависят от модели и компьютера. Наличие Ollama.exe ещё не означает, что сервис и модель готовы.

## Настройка

1. В «Подключениях» откройте официальный сайт провайдера и создайте ключ самостоятельно.
2. Вставьте его в поле с выбранным провайдером. Оставьте «Запомнить на этом ПК» выключенным для хранения только до выхода.
3. Нажмите «Использовать» для выбора ИИ. Для Groq/Gemini также выбирается их распознавание; Vosk можно вернуть в настройках.
4. В «Настройках» нажмите «Проверить ИИ». Это отправляет короткий тестовый вопрос и расходует квоту.
5. Нажмите микрофон и задайте вопрос.

Озвучка через Windows SAPI не расходует облачные токены. Установите русский голос средствами Windows, если он отсутствует. Jeffy использует только уже установленные голоса и не изменяет системные параметры.
