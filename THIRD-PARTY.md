# Third-party components

- [Electron](https://github.com/electron/electron): MIT. Chromium and bundled third-party notices are retained in the Windows distribution generated by electron-builder.
- [electron-builder](https://github.com/electron-userland/electron-builder): MIT, build tool.
- [Vosk API](https://github.com/alphacep/vosk-api): Apache-2.0; optional Python dependency installed locally.
- [vosk-model-small-ru-0.22](https://alphacephei.com/vosk/models): Apache-2.0; optional downloaded model, excluded from source repository. Mirror: [Rhasspy model archive](https://huggingface.co/rhasspy/vosk-models/blob/e7ac2109d134b5f2404ba95389b2fb51916d4cab/ru/vosk-model-small-ru-0.22.zip).
- Windows SAPI/System.Speech are operating-system components. Jeffy uses the user's installed voices and does not distribute Windows voice assets.

The Jeffy logo, layout and source code are original to this project. Luxify code, artwork, character voice packs and brand assets are not included.
